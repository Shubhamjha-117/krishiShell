# 🌾 krishiShell (SIH 2026 Project)

> **Smart India Hackathon 2026** | Problem Statement: SIH26132 – *Strengthening Market Linkages and Price Discovery for Farmers*

krishiShell is a web-based platform built by **Team Algonova** to bridge the gap between farmers and buyers. It empowers farmers to make data-driven selling decisions by comparing market prices, buyer demands, and logistical factors like distance.

### 🚀 Core Features
- **Farmer Dashboard:** List crop details, quantity, location, and preferred selling dates.
- **Buyer Portal:** Post specific crop requirements and demand volume.
- **Smart Matching Engine:** Connects relevant farmers with buyers based on crop type, distance, and price points.
- **Market Comparison:** Enables farmers to compare real-time factors across multiple buyers to maximize their profits.

### 💻 Technology Stack
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Backend:** Python (Flask)
- **Database:** PostgreSQL
- **Architecture:** RESTful APIs, JSON
